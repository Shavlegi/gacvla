# Gacvla — გაცვლა

საქართველოს ბანკებისა და გაცვლის პუნქტების ვალუტის კურსები ერთ ადგილას —
ლაივ განახლებებით, თითოეულ ბანკთან კალკულატორით.

🌐 საიტი: https://shavlegi.github.io/gacvla

## როგორ მუშაობს

- `index.html` + `styles.css` + `app.js` — საიტი (ქართული UI, მობილურისთვის).
  კურსებს `rates.json`-დან კითხულობს; ეროვნული ბანკის ოფიციალურ კურსს
  ბრაუზერიდანვე იღებს ლაივ API-დან.
- `scraper/scrape.py` — კურსების შემგროვებელი (Python, მხოლოდ საჯარო,
  გასაღების გარეშე, უფასო წყაროები). წყარო რომ ვერ განახლდეს, წინა ცნობილი
  კურსი რჩება — არაფერი ქრება და არაფერი იგონება.
- `.github/workflows/scrape.yml` — GitHub Actions, ყოველ 30 წუთში აწარმოებს
  სკრეპერს და `rates.json`-ს ანახლებს.
